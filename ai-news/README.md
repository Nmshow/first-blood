# 人工智能观察室

持续整理 OpenAI、Google、Microsoft、Anthropic、百度、腾讯等机构的公开 AI 资讯，并提供原始来源链接。网站界面和公开展示的资讯均使用简体中文。

## 本地预览

需要 Python 3.12 或更新版本；项目只使用 Python 标准库，无需安装第三方依赖。

```powershell
cd ai-news
python server.py
```

浏览器打开 <http://127.0.0.1:8000>。服务默认每 30 分钟检查一次来源，也可以在页面点“立即检查公开来源”。数据库首次启动时建立在 `data/ainews.sqlite3`。

## 自动整理英文来源

英文来源需要一个兼容 OpenAI Chat Completions 的摘要服务，才能自动翻译为简体中文。复制 `.env.example` 为 `.env`，配置服务地址、模型名和密钥后重新启动。服务只在英文原文可访问、来源域名与发布时间核对成功、且摘要返回中文标题、背景、摘要及事实点时，才将条目标为已核验。

未配置摘要服务时，英文新稿留在待处理状态；网页继续展示本地随附的人工核验样例。中文来源只有在读取到官方原文和可靠发布日期后才可自动进入精选。不要把 API 密钥提交到 GitHub。

## 来源与核验边界

- 自动采集只使用 `sources.json` 中登记的官网公开订阅源或公开页面，并检查对应 `robots.txt`。
- OpenAI、Google、Google DeepMind、Microsoft、Anthropic、百度和腾讯已列入官方来源登记表；应用会逐个显示实时接入状态。
- 知乎、微博和微信公众号当前显示为“暂未接入”。仅在确认有稳定、无需登录且符合平台公开访问规则的来源后，才会启用。
- 页面中的精选样例已人工回到一手来源核对，并保留原文链接。站点展示的“已核验”表示来源主体、发布日期及摘要证据经过核对，不代表对来源发布的全部主张作独立事实审计。
- 无法确认访问规则、来源页面不可达、发布时间缺失或中文整理失败时，条目留在待处理，不会凑数进入精选。

## 运维接口

- `/health`：服务状态。
- `/api/news`：当前已核验精选列表。
- `/api/status`：来源状态、待处理数量和最近采集时间。
- `POST /api/collect`：本机手动触发一次采集。

采集周期可通过 `COLLECTION_INTERVAL_MINUTES` 配置，超时可通过 `REQUEST_TIMEOUT_SECONDS` 配置。数据库文件位于 `data/`，备份时先停止服务，再复制该文件。
